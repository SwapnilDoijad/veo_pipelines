## Introduction
This is the repository for the VEO group (FSU, Jena). It contains hardcoded scripts designed to run on the Draco server.

## Prerequisites
- account at draco (i.e. URZ-id)
- access to the VEO group resources
	If you need an account please contact Bioinformatics Lab manager Dr. Swapnil Doijad (swapnil.doijad@gmail.com) or Prof. Dr. Bas Dutilh (b.e.dutilh@uni-jena.de)

## How to run the pipelines?
1. (Optional but recommended) install [VS code](https://code.visualstudio.com/)
2. Connect VS code to Draco ([help](https://docs.google.com/presentation/d/1iwcY53l5vtkwYEJqqDmUZ8V2zA9KT8KaXf8OHaU7O5c/edit?slide=id.g2c21ca83cdc_0_106#slide=id.g2c21ca83cdc_0_106))
3. Prepare your project directory ([help](https://docs.google.com/presentation/d/1E6FClEcDKRZT2V8DkHAYMov8dxp2Se2xCMIAazn9Xo4/edit?slide=id.g1f3df50c465_0_14#slide=id.g1f3df50c465_0_14))
4. Run the pipelines using the integrated terminal ([help](https://docs.google.com/presentation/d/1E6FClEcDKRZT2V8DkHAYMov8dxp2Se2xCMIAazn9Xo4/edit?slide=id.g1f3df50c465_0_14#slide=id.g1f3df50c465_0_14)).
